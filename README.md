# Deep Learning J4 — RNN, LSTM, GRU

Prévision de séries temporelles et classification de texte avec des réseaux de neurones récurrents (Keras 3), et déploiement en WebApp Streamlit.

## Prérequis

- Docker

## Lancer

```bash
docker compose up
```

- Jupyter : http://localhost:8888
- TensorBoard : http://localhost:6006

## Contenu

- `airline_passengers.ipynb` — prévision de la série temporelle Airline Passengers (LSTM).
- `Dockerfile` / `docker-compose.yml` / `requirements.txt` — environnement TensorFlow 2.18 / Keras 3.

## Stack

Python 3.11 · TensorFlow 2.18 · Keras 3 · scikit-learn · Streamlit
